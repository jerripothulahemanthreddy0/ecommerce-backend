# E-Commerce Backend API

A RESTful E-Commerce Backend API built using Java and Spring Boot. The project provides user, product, and order management with JWT-based authentication, input validation, global exception handling, and unit testing.

## Technologies Used

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- JWT
- Jakarta Validation
- JUnit 5
- Mockito
- Postman
- Maven

## Features

- User CRUD operations
- Product CRUD operations
- Order CRUD operations
- JWT authentication
- Protected REST APIs
- Input validation
- Global exception handling
- MySQL database integration
- Unit testing with JUnit 5 and Mockito
- API testing with Postman
